# 齿轮护符

<ItemImage id="anvilcraft_create_addition:cogwheel_amulet" scale="3"></ItemImage>

# 获得

通过 <ItemLink id="anvilcraft:amulet_box" /> 的功能获得，需要死于机械动力的机器（如动力锯）的伤害
 
# 功能

生效时完全免疫机械动力机器的机械伤害（包括动力锯、粉碎轮、动力钻头）

> 只限于机械伤害，所以熔岩吹风机的热风还是会造成伤害
