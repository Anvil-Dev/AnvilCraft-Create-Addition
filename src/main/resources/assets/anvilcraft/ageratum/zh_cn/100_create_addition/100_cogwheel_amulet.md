# <ref item="anvilcraft_create_addition:cogwheel_amulet"/>

<item id="anvilcraft_create_addition:cogwheel_amulet"/>

# 获取

详见[护符](../006_prop/100_amulet.md#获取)，需要受到由机械动力本体相关事物（如<ref item="create:mechanical_saw"/>）导致的致命伤害
 
# 效果

- 完全免疫机械动力机械动力相关事物的伤害（包括<ref item="create:mechanical_saw"/>、<ref item="create:crushing_wheel"/>、熔岩<ref item="create:encased_fan"/>吹出的热风等）

> 仅支持机械动力本体，其它附属新增的伤害类型、对机械动力本体作出的改动不保证生效

- 自带<ref item="create:goggles"/>效果
- 摇动<ref item="create:hand_crank"/>或<ref item="create:valve_handle"/>时产出八倍应力
