# 加热锅炉

铁砧工艺的<ref item="anvilcraft:heater"/>、部分[高温方块](../001_feature/101_heated_block.md)和部分[超温方块](../001_feature/301_overheated_block.md) 放置在锅炉底下，可以为锅炉提供热量，具体数值如下：

- 工作的<ref item="anvilcraft:heater"/>：1级
- <color=#aa2222>红热</color>的方块：1级
- <color=#cc5533>炽热</color>的方块：2级
- <color=#ee7744>白炽</color>的方块：3级
- <color=#6688cc>超温</color>的方块：4级

> 高温方块可同时为*锅炉*和<ref item="anvilcraft:heat_collector"/>提供能量，一热两用！
